Method. Daily precipitation from ECMWF ERA5 reanalysis (via the Open-Meteo Historical Weather API), aggregated monthly. SPI = Standardized Precipitation Index (gamma fit per calendar month, 1991–2020 baseline); ≤ −1 is moderate drought or worse. “30-day rain” compares the latest 30 days with the 1991–2020 mean for the same window. ERA5 lags real time by roughly 5–7 days. Point values represent the ERA5 grid cell at each city and are a proxy for the surrounding region. Data refreshed daily by GitHub Actions.
