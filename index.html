Method. Daily precipitation from ECMWF ERA5 reanalysis (via the Open-Meteo Historical Weather API) aggregated to months. SPI = Standardized Precipitation Index (gamma fit per calendar month, 1991–2020 baseline); ≤ −1 is moderate drought or worse. SPI-3 = last 3 months, SPI-12 = last 12 months. “30-day rain” compares the latest 30 days with the 1991–2020 average for the same dates. Each marker is one ERA5 grid-cell sample (country centre point, or a Central Asian agricultural focus point), not an area average — large countries are only roughly represented. SPI is hidden (n/a) in hyper-arid places (<100 mm/year). ERA5 lags real time by about 5–7 days. The situation briefing is generated only from the computed indicators; when AI-written, verify against the table. Data refreshed automatically by GitHub Actions.
